# Transaction Reconciliation and Analysis Project

## Overview
This project focuses on performing comprehensive transaction reconciliation and analysis to identify discrepancies, assess financial impact, and gain insights into merchant performance and risk factors. It processes transactional data from various sources (internal systems, gateway, ledger, API) to provide a holistic view of the payment ecosystem.
- `01_data/processed`: Contains all cleaned and processed CSV files generated during the analysis.
- `02_spreadsheet`: Contains reconciliation reports and an empty placeholder for a spreadsheet workbook.
- `03_sql`: Contains SQL analysis queries and answers.
- `04_python`: Contains Python scripts and generated summary JSONs.
- `05_visualization`: Contains generated dashboard images and an empty placeholder for a dashboard link.
